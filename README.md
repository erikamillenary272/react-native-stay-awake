# react-native-stay-awake

Keep the screen awake in React Native. New Architecture (TurboModule) first, with hooks, reference counting, and web support.

## Installation


```sh
npm install react-native-stay-awake
```


## Usage


```js
import { multiply } from 'react-native-stay-awake';

// ...

const result = multiply(3, 7);
```
